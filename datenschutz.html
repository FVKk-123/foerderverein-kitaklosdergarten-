2. Besuch der Website

Unsere Website ist als statische Website für GitHub Pages aufgebaut. Wir setzen auf dieser Website keine eigenen Analyse-, Werbe- oder Trackingdienste und keine externen Schriftarten ein.

Bei der Nutzung von GitHub Pages wird nach Angaben von GitHub die IP-Adresse eines Besuchers aus Sicherheitsgründen protokolliert und gespeichert. Für diese Verarbeitung ist GitHub verantwortlich. Weitere Informationen finden Sie in den Datenschutzbestimmungen von GitHub.

3. Kontakt per E-Mail

Wenn Sie uns per E-Mail kontaktieren, verarbeiten wir die von Ihnen mitgeteilten personenbezogenen Daten zur Bearbeitung Ihrer Anfrage. Die Daten werden nicht zu Werbezwecken verwendet. Eine Weitergabe erfolgt nur, wenn sie zur Bearbeitung erforderlich ist oder eine gesetzliche Verpflichtung besteht.

5. Ihre Rechte

6. Keine Cookies durch den Verein

Die Website setzt von uns keine eigenen Cookies und verwendet keine eingebetteten Karten, Videos, Social-Media-Feeds oder Analysewerkzeuge.
